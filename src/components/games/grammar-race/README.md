# Грамматические гонки

Общие экраны, игровое ядро и контракты для коротких игр против компьютера.
Конкретная игра передаёт `GrammarRaceDefinition`, а задания и параметры робота
приходят в серверной игровой сессии.
Цель матча также приходит с сервера: она равномерно растёт от 5 очков на
первом уровне до 10 очков на последнем уровне каждой игры.

Каждое задание приходит как `type + payload + options`. Компонент
`GrammarRaceTaskHost` выбирает визуальный компонент по `type`. Сейчас
реализован `single_choice`: его payload содержит текст с маркером `___`, а
options — стабильные идентификаторы и подписи вариантов.

- `A sister ___` — личные местоимения;
- `___ book` — притяжательные местоимения;
- `___ apple` — артикли;
- `She ___ at school today` — формы глагола `to be`.

Для добавления игры достаточно создать отдельную папку рядом с `pronoun`,
описать её конфигурацию, серверную реализацию `GrammarRaceGame` и генератор,
а затем передать код игры в `GrammarRaceGame`. Для нового формата задания
добавляются серверный evaluator и Vue-компонент в `tasks`, после чего они
регистрируются в соответствующих реестрах. Общий компонент управляет таймером,
счётом, офлайн-очередью, выходом и повторным запуском.

В `assets` находятся состояния персонажей, общие для всей группы игр:

- `student-happy.png` и `student-sad.png`;
- `robot-happy.png`, `robot-sad.png` и `robot-thinking.png`.
