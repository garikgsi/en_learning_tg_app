# Грамматические гонки

Общие экраны, игровое ядро и контракты для коротких игр против компьютера.
Конкретная игра передаёт `GrammarRaceDefinition`, а задания и параметры робота
приходят в серверной игровой сессии.

Каждое задание содержит текст с одним маркером `___`, варианты ответа и
правильный ответ. Поэтому один и тот же экран поддерживает разные позиции
пропуска:

- `A sister ___` — личные местоимения;
- `___ book` — притяжательные местоимения;
- `___ apple` — артикли;
- `She ___ to school` — формы глагола.

Для добавления игры достаточно создать отдельную папку рядом с `pronoun`,
описать её конфигурацию, серверный генератор и передать код игры в
`GrammarRaceGame`. Компонент управляет таймером, счётом, офлайн-очередью,
выходом и повторным запуском.

В `assets` находятся состояния персонажей, общие для всей группы игр:

- `student-happy.png` и `student-sad.png`;
- `robot-happy.png`, `robot-sad.png` и `robot-thinking.png`.
