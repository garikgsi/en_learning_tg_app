# Theme usage

- Use `logo/logo-wordmark.svg` on light backgrounds. Its text color is
  `#4B2142`; contrast against `#FFF2F8` is 12.10:1.
- Use `logo/logo-wordmark-on-dark.svg` on dark backgrounds. Its text color is
  `#FFF2F8`; contrast against the recommended `#2B1227` background is 15.85:1.
- Do not recolor the symbol when switching themes. Only the wordmark text
  changes between the light and dark variants.
- Keep the prohibited blue-and-yellow color pairing out of all themes.
