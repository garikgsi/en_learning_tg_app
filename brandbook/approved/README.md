# Утверждённая айдентика

## Решение

- конструкция: Refined original;
- палитра: вариант 03 Berry Cloud;
- подложка и негативное пространство: `#FFF2F8`;
- контейнер: `#4B2142`;
- верхняя стрелка: `#E85D9E`;
- нижняя стрелка и badge: `#9B8AFB`.

Production-мастер использует плоские заливки без теней и градиентов. Это сохраняет читаемость launcher icon и favicon на малых размерах.

## Структура

- `logo/` — векторные мастера;
- `exports/icons/` — PNG знака от 16 до 1024 px;
- `exports/promo/` — Telegram, Open Graph и Store-изображения;
- `exports/splash/` — мастер splash;
- `generate_assets.py` — воспроизводимая генерация PNG/ICO и Android density-ресурсов;
- `assets-manifest.json` — перечень конечных файлов и назначений.

Android APK не собирается этим скриптом. Он только обновляет графические ресурсы проекта.
