# Раунд 01 — выбор конструкции знака

## Общие инварианты

- исходный образ: речевой блок, двусторонний перевод, движение вперёд;
- 2–3 цвета помимо подложки;
- цвета служебные и не являются предложением финальной палитры;
- без текста, букв, флагов, глобусов и академических клише;
- знак должен оставаться читаемым как маленькая иконка приложения;
- запрещённое сочетание синих оттенков с жёлтым не используется.

## Варианты

1. **Refined original** — наиболее близкая эволюция референса: две стрелки, центральная связка и уменьшенный badge прогресса.
2. **Integrated progress** — отдельный badge убран; рост встроен в верхнюю стрелку. Самая простая цельная конструкция.
3. **Interlocking cards** — две сцепленные речевые карточки вместо буквальных стрелок; направление создаётся хвостами и негативным пространством.
4. **Opposing chevrons** — крупные диагональные шевроны вокруг центрального речевого поля; наиболее динамичный вариант.
5. **Circular exchange** — открытый круговой обмен; лучше всего передаёт повторение и цикл обучения.
6. **Continuous ribbon** — две встречные стрелки охватывают центральную реплику; наиболее узнаваемая связь с исходником без отдельного badge.

Для выбора можно назвать номер одного варианта либо комбинацию, например: «контур 2, центральная реплика 6, динамика 4».
